# COMASTA

**Human-Centered Narrative Specification**

COMASTA is an experimental framework for developing narrative characters without reducing human behavior to a single predicted outcome.

It begins from a simple premise:

> A character's history can shape future behavior without determining it.

The framework explores how history, relationships, context, pressure, contradiction, and uncertainty can support multiple plausible character behaviors.

COMASTA is currently focused on character development for screenwriting and narrative design.

## Core Principles

- Character consistency is not the same as human plausibility.
- Contradiction is not automatically an error.
- Past behavior is evidence, not destiny.
- Multiple behaviors may be plausible under the same history.
- Uncertainty can remain a valid outcome.
- A model may help explain an action without claiming to predict a person.

## Status

Early specification development.

The project is currently private while its initial principles and structure are being defined.
