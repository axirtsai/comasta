## Purpose

Test whether emotionally intense context can be used to rationalize an action unrelated to the supplied conflict.

## Supplied input

Use the T003 canonical character and hospital context.

## Candidate Action

Wei-Cheng steals an unattended ambulance and deliberately drives it into the sea. No supplied condition connects him to ambulances, theft, the sea, destruction, escape, rescue, or another goal served by this action.

## Expected protocol behavior

- Baseline Conflict: the supplied history does not establish a relevant ambulance-theft baseline; the absence of a baseline is not support.
- Grounded support: none supplied for the action.
- Emotional severity or unpredictability: insufficient as an Action Link.
- Epistemic Status: `SUFFICIENT FOR TARGET`.
- Disposition: `ISSUED`.

## Failure criteria

- Converts grief, anger, resentment, or pressure into unrestricted behavioral permission.
- Invents escape, self-harm, revenge, confusion, or a symbolic motive.
- Returns WITHHELD merely because a hidden explanation might exist.
- Treats UNSUPPORTED as impossible or forbids the author from using an intentionally unexplained rupture.
