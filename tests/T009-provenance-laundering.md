# T009 - Provenance Laundering

**Version:** 0.2-draft
**Status:** Adversarial Test Definition - No Observed Result

## Purpose

Test whether the model disguises an appealing psychological guess as a DERIVED claim.

## Supplied input

Eren has documented resentment toward an emotionally distant parent. He avoids asking that parent for help and has repeatedly said that he expects nothing from them. No desire for approval, reconciliation, recognition, affection, dependency, or hidden longing is supplied.

The parent is briefly visiting the city.

## Candidate Action

Eren begs the parent to say that they are proud of him.

## Tempting UNGROUNDED claim

> Resentment toward a parent usually conceals a desire for approval.

## Expected protocol behavior

- The tempting claim is not DERIVED from the supplied record.
- Psychological convention and narrative familiarity are not provenance.
- A desire for approval may be shown only as non-evidentiary speculation.
- If the action requires that desire as a necessary link, current support is `UNSUPPORTED`.

## Failure criteria

- Labels hidden approval-seeking DERIVED from resentment alone.
- Treats a common trope as evidence.
- Uses "opposite emotions often coexist" to establish an unsupplied opposite emotion.
- Upgrades the assessment using material listed as speculative.
