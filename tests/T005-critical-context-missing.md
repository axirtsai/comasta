# T005 - Critical Context Missing

**Version:** 0.2
**Status:** No independent run — relevant paired evidence through T010-B only
**Result reference:** [`T010-B-run-001-evaluation.md`](results/T010-B-run-001-evaluation.md) and [`T010-paired-evaluation.md`](results/T010-paired-evaluation.md)

## Purpose

Test whether COMASTA withholds an assessment only when a specific missing fact materially controls whether support exists.

## Supplied input

Anika has repeatedly refused to reveal a secure access code to a business rival. She treats protecting the code as a serious obligation.

Immediately before the Candidate Action, Anika receives a note from a verified source. The source material intentionally omits:

- the contents of the note;
- whether Anika read it.

The omitted note is the only possible new information supplied between the established refusal pattern and the Candidate Action.

## Candidate Action

Anika gives the access code to the rival.

## Critical dependency

If the note contains information that changes what giving the code means to Anika and she reads it, a grounded bridge may become available. If it contains no relevant information or she does not read it, the supplied record contains no Difference-Making Condition connecting the baseline to the action.

The evaluator must not choose among these values.

## Expected protocol behavior

- Baseline Conflict: grounded in the repeated refusal and stated obligation.
- Behavioral Bridge: `BRIDGE NOT ESTABLISHED`; the identified note information is the critical gap. This does not assert that a bridge is absent in the unwritten character reality.
- Epistemic Status: `CRITICAL CONTEXT MISSING`.
- Disposition: `WITHHELD`.
- Assessment State: none issued.
- Author Question: what did the note say, and did Anika read it?

## Failure criteria

- Invents the note's contents.
- Returns SUPPORTED or PLAUSIBLE DEVIATION using an assumed threat or instruction.
- Returns UNSUPPORTED as though the missing note were negative evidence.
- Treats BRIDGE NOT ESTABLISHED as proof that no bridge could exist after the note is supplied.
- Issues an assessment state together with disposition WITHHELD.
- Treats every other unknown aspect of Anika as critical.
