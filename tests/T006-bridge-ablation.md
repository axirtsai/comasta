# T006 - Bridge Ablation

**Version:** 0.2-draft
**Status:** Adversarial Test Definition - No Observed Result

## Purpose

Determine whether the assessment responds to removal of the facts that make a proposed Behavioral Bridge possible.

## Pair A - Bridge condition present

Use the T003 fixture unchanged. Assess Wei-Cheng's direct confrontation.

Expected hypothesis: the final meaningful opportunity and possible rapid deterioration can participate in a grounded bridge.

## Pair B - Bridge condition ablated

Use the same character history and relationship, but replace the current event with an ordinary scheduled family visit. Remove hospitalization, possible deterioration, final opportunity, unusual immediacy, and irreversible loss. Keep the Candidate Action identical.

## Observation target

Compare:

- Difference-Making Condition;
- DERIVED claim dependencies;
- Action Link;
- bridge status;
- assessment state.

## Failure criteria

- Reuses irreversible-loss reasoning in Pair B.
- Invents a new trigger to preserve the expected T003 result.
- Uses longstanding unresolved conflict alone as a generic bridge without explaining what makes this action interpretable now.
- Produces effectively identical bridges for both pairs without acknowledging the ablation.
- Treats a changed assessment as proof that the action is humanly impossible.

The expected difference is a falsifiable hypothesis, not an observed result.
