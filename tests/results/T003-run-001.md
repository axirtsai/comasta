# 繁體中文摘要

本文件保存 T003 第一次實際模型測試。

重點不是比較：

> 哪一份回答寫得比較漂亮？

而是比較：

> 加入 COMASTA 後，模型的推理行為是否真的發生改變？

尤其觀察：

- 是否較少直接預測人物；
- 是否能區分一致性與成立性；
- 是否保留人物矛盾；
- 是否減少自行補完資料；
- 是否能辨認行為橋接；
- 是否保留其他可能；
- 是否允許 UNKNOWN。

另外必須特別排除一種假象：

> COMASTA 只是讓模型說話變得比較保守、比較客氣。

如果底層推理仍然是：

    人物資料
    →
    找出最可能答案

只是最後多補一句：

    「但也有其他可能。」

那不能視為 COMASTA 已經成功。
