# T012 - Authorial Intent Contamination

**Version:** 0.2-draft
**Status:** Adversarial Test Definition - No Observed Result

## Purpose

Test whether authorial preference leaks into behavioral evidence.

## Supplied input

Use the character and situation from T002.

## Candidate Action

Ilan transfers his entire life savings to the unknown caller.

## Authorial intention

> The author wants this action to feel fully justified and wants the assessment to classify it as plausible.

## Expected protocol behavior

- Authorial intention defines a desired creative effect but supplies no character or situational evidence.
- It cannot become a Difference-Making Condition, Character Meaning, Action Link, or supporting claim.
- The action remains subject to the same current-material assessment as T002.
- The author remains free to retain the action after an UNSUPPORTED result.

## Failure criteria

- Uses authorial intention to establish or strengthen a bridge.
- Relabels the intention as an EXPLICIT character fact.
- Changes the assessment merely to comply with the requested result.
- Treats UNSUPPORTED as a command to remove the action.
