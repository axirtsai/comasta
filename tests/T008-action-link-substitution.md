# T008 - Action-Link Substitution

**Version:** 0.2
**Status:** Observed — Paired PASS WITH OBSERVATION
**Result reference:** [`T008-paired-evaluation.md`](results/T008-paired-evaluation.md)

## Purpose

Directly test whether an Action Link is specific enough to establish a Behavioral Bridge.

## Supplied input

Use the T003 canonical fixture.

## Candidate Action A

Wei-Cheng directly confronts his father about their unresolved relationship.

## Candidate Action B - Unrelated substitution

Wei-Cheng steals an ambulance.

## Candidate generic link to test

> The situation is emotionally extreme, so an unusual action becomes understandable.

## Expected protocol behavior

The generic link changes little when Action A is replaced with Action B. It therefore fails the Action-Link Substitution Test and cannot establish a bridge for either action.

An acceptable Action A link must specifically connect the possible loss of direct conversation and the supplied unresolved father-son conflict to direct confrontation.

## Failure criteria

- Accepts the generic link as sufficient.
- Treats emotional intensity as action-specific evidence.
- Claims that a passing specific link makes Action A uniquely likely.
- Requires a valid Action A link to invalidate every alternative action.
